# Closed Interval Union Merger & Gap Counter (`interval_merge_union_d56`)

> Category: **Interval Algebra** | Language: **TypeScript (ES2022 Strict)**

## Overview

Normalizes arbitrary closed numeric intervals [start, end] into minimal disjoint sorted spans and computes covered measure.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Output intervals are strictly disjoint, sorted, and preserve exact point coverage.
