# Scientific TypeScript Algorithms

Strictly typed numerical algorithms, mathematical approximations, rational expansions, and recurrence sequences in modern TypeScript.

## Modules
- `continued_fractions`: Generalized continued fraction approximants
- `pade_approximants`: Rational polynomial approximations
- `chebyshev_collocation`: Chebyshev-Gauss-Lobatto spectral node evaluations
- `fibonacci_matrix_power`: Matrix recurrence and generalized sequence generators
- `spherical_harmonics_terms`: Associated Legendre components and radial basis functions

## Requirements
- Node.js v20+ and TypeScript 5+ (`npm run build` or `tsc --noEmit`)
